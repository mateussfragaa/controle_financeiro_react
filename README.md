# Controle Financeiro

Aplicação web desenvolvida em React para auxiliar no controle financeiro pessoal.

## Funcionalidades

- Página inicial
- Página de transações
- Página sobre
- Navegação entre páginas
- Inserção de uma transação

## Tecnologias

- React
- Vite
- JavaScript
- HTML
- CSS

## Como executar

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Instale as dependências:

npm install

4. Execute o projeto:

npm run dev
